## 🧰 Ce que je fais

Technicien informatique indépendant à Boulogne-sur-Mer, je combine intervention terrain et développement logiciel :

- 🔧 **Réparation** d'ordinateurs, PC et portables (domicile & atelier)
- 💾 **Récupération de données** sur tous supports (NTFS, FAT32, carving)
- 🛡️ **Sécurisation & maintenance** de parc informatique
- 🚀 **Développement** de logiciels Windows sur mesure, du diagnostic système aux outils métier
